# life-goals-app

Application mobile de suivi d'objectifs personnels, en React Native.

## Structure

`src/features/goals/` porte la fonctionnalite d'objectifs, `src/components/` les composants
partages, `src/app/store.js` le store Redux. `src/features/counter/` est l'exemple fourni
par le modele Redux Toolkit.

`guide_debutant.md` accompagne la prise en main.

## Stack

Expo, React Native, Redux Toolkit avec React Redux, `react-native-confetti-cannon`.

## Lancer

```sh
npm install
npm start
```

`npm run android`, `npm run ios` ou `npm run web` pour cibler directement une plateforme.
